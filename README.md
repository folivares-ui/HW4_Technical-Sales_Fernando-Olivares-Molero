# The Business Table — Business Dining Etiquette Website (HW4)

Static website (HTML, CSS, JS — no build step). Open `index.html` in a browser, or publish with GitHub Pages.

- `index.html` — guide, interactive place setting, before/during/after checklists, 4 games, video lesson, Carreño flip cards
- `survey.html` — survey questions (internal link target) and sources
- External links: OpenTable, course-suggested resources

## Optional: embed a real YouTube video
In `index.html`, set `data-video-id` on `<div id="ytWrap">` to an 11-character YouTube ID. A "full video" player then appears under the animated lesson.
